# Birthday Bot

**A simple app that keeps track of birthdays and sends a phone notification at 8:00 in the morning on the day.**

It's for anyone who has a list of friends' birthdays and keeps forgetting them. You add birthdays once, and a server sends the reminder every morning, even if you haven't opened the app. It works in a phone's web browser and can be added to the home screen so it looks and behaves like a regular app.

## What you can do with it

- See all upcoming birthdays in order, grouped into today, this week, this month and later, with how many days are left.
- See how old each person is turning, if you know the year they were born. The year is optional.
- Add and edit birthdays by hand.
- Import a whole list at once from a spreadsheet (CSV) or data file (JSON), with a preview before anything is saved.
- Turn on morning reminders on your phone, and send yourself a test notification.
- Optionally lock the app behind a passcode so only you can see the list.
